# 异世界裂缝查看器｜手机姿态 Demo v0.2

沿用原 `paranormasight-panorama-replica` 的风格化 2:1 全景素材 `assets/bg08_d.png` 和 WebGL2 固定视点观察器。v0.2 在原 v0.1 的“按住观察、松开冻结、再按住相对校准”之上，增加**回到最初握持姿态自动回正**。

## v0.2 新功能

**首次按住**时保存一个长期物理姿态基准 `origin`。每次按住仍创建独立的临时相对旋转基准，不要求手机先摆平。只要网页保持前台、已授权姿态传感器，松开按钮之后仍继续采样设备方向，但**画面保持冻结**。

当系统确认以下条件同时成立，便把全景视角平滑返回预设正前方：

1. 用户曾经在**按住观察**时离开长期基准至少约 **17°**（避免日常晃动导致误回正）。
2. 松开按钮后，手机姿态重新回到长期基准 **9°** 以内。
3. 在附近稳定停留约 **420ms**；不能只是转动过程中经过这一方向。
4. 触发后使用约 **650ms** 平滑动画回到场景正前方，而不是突然跳画面。

每次回正后检测器会解除待回位状态，避免持续重复触发。重新按住可中断回正动画并从当前画面继续。触摸拖拽、键盘操作也会中断回正。

界面提供“自动回位”开关（默认开启）；“回正 / 设基准”既能恢复场景正前方，也能把**当前握持姿态设为新的长期基准**。横竖屏切换会重新建立长期姿态基准，以免屏幕坐标系突变造成误判。

**限制：** 它检测的是**设备姿态**，不是手机在房间里的空间位置。设备朝向的绝对水平航向可能漂移，重力传感器无法单独确定东南西北。网页进入后台、切换应用或手机锁屏后，浏览器往往暂停传感器事件；本项目不会尝试系统后台追踪。

## 手机试玩

GitHub Pages: https://lupy19819.github.io/gyro-demo/

1. 在手机 Safari / Chrome 打开 HTTPS 链接，点击“启用方向感应”，允许权限。
2. 将手机以**任意舒适姿态**拿好；第一次**按住观察**时记录长期基准。手机此刻朝下也不会让画面跳到地面。
3. **按住**转动手机，探索左右/上下；**松开**冻结画面。
4. **无需再按住**，将手机转回第一次握持姿态，稍作停留，检查画面是否自动回到正前方。
5. 想把现在的握持姿态当新基准，点“回正 / 设基准”。
6. 想恢复 v0.1 的松开冻结、不自动回正行为，关闭“自动回位”。

若第一次没转动超过 17°，则不会进入待回位状态；这属于防误触发设计。

## 本地运行与测试

```bash
python3 -m http.server 5173
# Mac 浏览器打开 http://localhost:5173
node tests.mjs
```

手机传感器通常需要 HTTPS；在手机上访问 Mac 的局域网 HTTP 地址可能只能拖拽、读不到传感器。

### 文件

- `app.js`：全景渲染、UI、指针操作、逐帧回正动画调度
- `gyro.mjs`：权限、设备姿态、临时 Clutch 校准、长期基准管理
- `gyro-math.mjs`：四元数、设备方向到视角转换
- `return-detector.mjs`：回位检测纯逻辑、角度阈值、回位停稳与防误判
- `tests.mjs`：四元数和回位检测单元测试
- `assets/bg08_d.png`：当前个人实验使用的原游戏素材

## 手工验收

| 操作 | 预期 |
|---|---|
| 手机低头时首次按住 | 画面不跳；以当前姿态记基准 |
| 按住转动 30° | 视角随手机移动 |
| 松开、停在右侧 | 画面冻结；不立刻回正 |
| 松开后转回首次姿态、停稳约 0.4 秒 | 约 0.65 秒平滑回到正前方 |
| 从基准附近快速掠过 | 不触发回正 |
| 观察中切换横竖屏 | 自动重建基准，不误触发 |
| 回正时再次按住 | 中断动画，从当前画面继续 |
| 点“回正 / 设基准” | 正前方重置，当前设备姿态变成新基准 |
| 关闭“自动回位” | 保留 v0.1 的松开冻结模式 |
