# 异世界裂缝查看器｜手机姿态 Demo v0.5

基于原 `paranormasight-panorama-replica` WebGL2 2:1 球面全景，直接复用 `assets/bg08_d.png`。

## v0.4 开启/冻结演出

- 获得姿态权限后默认进入**灰白色的冻结态**；画面仍保持可辨识的材质与层次。
- **按住观察**：短促青绿色波纹向外扩散，灰白解除，恢复原图色彩。
- **松开**：短暂冰白封印波纹，场景逐渐转为低饱和银灰色，表现时间停滞。冻结期间相机视角不再跟随手机，传感器仍持续更新最新姿态。
- **再次按住**：照 v0.3 的正确规则，立刻显示手机当前姿态对应的视角，不会重新校准丢弃松手期间的物理转动。
- 动效在已有 WebGL2 Shader 中完成，无额外美术素材；CSS 边缘框和冻结薄雾仅作轻量点缀，不阻挡任何触摸操作。
- 快速连按/松开时颜色混合值连续，不会突然闪回；系统“减少动态效果”设置会关闭额外波纹（保留必要的状态变化）。

## v0.3 行为（继续保留）（修复 v0.2 的理解偏差）

> **首次按下校准一次；松开只冻结画面，但继续记录手机姿态；在松开的期间移动手机，下一次按住立即显示手机新朝向对应的画面。**

举例：

1. 第一次按住：此刻手机朝向对应场景正前方；允许手机从任意倾斜姿态开始。
2. 按住并向右转 30°：画面看向右侧；松开：画面保持右侧。
3. **松开期间把手机转向左侧 30°**：画面仍冻结在右侧，但后台（仅网页前台）继续采集姿态。
4. 再次按住：**立即切换至左侧 30°**，而不是在右侧重新开始相对转动。
5. 松开后把手机转回最初姿态，再按住：对应初始正前方。

v0.2 错误地仍在每次按下时 `reanchor`，导致丢失松开期间的运动；“检测到回到起始点后自动回正”也与这里的需求不同。**v0.3 删除自动回正手势**，保留长期姿态原点直到点击“回正 / 重设基准”或手机屏幕方向切换。

## 原理

- `originDevice`：首次按住记录的姿态四元数，在连续按放之间**不再变化**。
- `originView`：首次按下时的虚拟相机方向。
- `latestDevice`：网页处于前台时不断更新的手机姿态，即使松开也继续记录。
- `view = relativeView(originView, originDevice, latestDevice)`：只在**按住期间**应用到画面；但每次重新按住立即计算一次最新目标并同步视角。
- 横竖屏切换：旧的屏幕坐标系不再可比较，以当前手机姿态 + 当前画面重新对齐一次。
- 按「回正 / 重设基准」：场景视角归零，同时把当前手机姿态变成新的长期原点。

**限制**：这是 3DoF 姿态，不追踪设备平移；不同设备的航向漂移仍可能存在。iOS/Android 浏览器在切换 App、锁屏或网页退入后台时一般会暂停传感器。返回页面后若传感器没有新鲜数据，观察按键会拒绝启动而不是使用旧姿态。

## 运行

手机 HTTPS 页面：https://lupy19819.github.io/gyro-demo/

本地 Mac：

```sh
python3 -m http.server 5173
node tests.mjs
```

首次点击「启用方向感应」授权，之后按住下方按钮操作。保留手指拖拽与手动回正。

## 手动验收

| 动作 | 预期 |
| --- | --- |
| 手机最初朝下，首次按住 | 不跳；以当时姿态为基准 |
| 按住右转 30° | 画面转向右侧 |
| 松开，手机转到左侧 | 画面冻结，但跟踪读数变化 |
| **再次按住** | **直接显示左侧对应位置**，不从原画面重新累计 |
| 松开，手机回到首次方向，再按住 | 回到场景正前方 |
| 多次按住、松开、原地不动 | 画面无持续漂移/累计偏移 |
| 横竖屏切换 | 不误把横竖屏变化当作大角度转身 |
| 回正 / 重设基准 | 当前手机姿态成为新的正前方 |
